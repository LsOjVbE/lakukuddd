# 提示词模板库

> 直接复制到 WorkBuddy 对话中使用。核心原则：
> **给目标、给约束、给验收标准** —— 而不是只说"帮我做/帮我部署"。

---

## 一、验证连接器链路

```
查询我账号中有哪些 Lighthouse 实例，
按表格列出版本地域、实例 ID、实例名称、状态、配置规格、公网 IP、到期时间。
```

---

## 二、配置云侧防火墙

```
请为我的 Lighthouse 实例（实例 ID：lhins-xxxxxx）配置防火墙规则：
放行 TCP 22（仅限我的常用出口 IP）、80、443，
并返回当前已生效的全部规则。
注意区分云侧安全组与系统内 ufw，两层状态都汇报给我。
```

---

## 三、Vibe Coding 生成项目

```
请帮我开发一个「个人作品集 + 留言板」网站。

【目标】展示我的 3 个作品，访客可留下一条留言。
【技术栈】Node.js 20 + Express + 原生 HTML/CSS/JS，数据存本地 SQLite 文件，
          不要引入 React 等前端框架，不要用外部 CDN 资源。
【验收标准】
  1. 首页展示作品列表，移动端单列、桌面端三列；
  2. 提交留言后立即出现在列表中，无需刷新整页；
  3. 留言过长（>200 字）返回 400 并给出提示；
  4. GET /healthz 返回 200 与 {"status":"ok"}。
【工程约束】
  1. 端口从环境变量 PORT 读取，默认 3000；
  2. 提供 .env.example、README.md（含启动说明）；
  3. 提供可用的 Dockerfile，使用 alpine 基础镜像，非 root 用户运行；
  4. 数据文件路径可通过环境变量配置，便于挂载持久化卷。

先给出目录结构与实现计划，我确认后再写代码。
```

## 四、安装自建 PaaS 面板

```
请在服务器 123.45.67.89 上安装 Coolify（自建 PaaS 面板）。
要求：
1. 使用官方安装脚本，安装完成后报告面板访问地址与初始账号；
2. 确认 Docker 与 Traefik 组件已正常运行；
3. 把面板端口加入云侧防火墙，并说明如何在控制台看到它；
4. 全程输出每一步实际执行的命令与结果，不要省略报错。
```

---

## 五、部署到服务器（核心模板）

```
请阅读 deploy-kit/server_info.md，把当前项目部署到该 Lighthouse 服务器。

要求：
1. 使用 SSH 私钥连接，不要改动机器上与本项目无关的目录；
2. 应用目录固定为 /opt/my-vibe-app，保持可重复部署（已存在则先备份再覆盖）；
3. 用 Docker Compose 启动，容器端口绑定 127.0.0.1:3000；
4. 用 Nginx 反向代理 app.example.com 到 127.0.0.1:3000，并确认已启用 HTTPS；
5. 放行云侧与系统侧的必要端口，其余保持关闭。

完成后请用表格返回以下信息，缺一不可：
- 实际部署路径、容器名、服务端口
- Nginx 配置路径与 reload 命令
- 进程管理方式与重启命令
- 一条回滚到上一版本的操作步骤
- 从公网访问首页与 /healthz 返回的状态码
```

## 六、上线体检（从公网出发）

```
网站已部署上线，域名是 https://app.example.com。
请从公网访问一次，做完整上线体检，用表格返回结果：

1. 首页、列表页、任选一个详情页，各自返回的状态码；
2. 随机抽 5 个静态资源（图片/CSS/JS）逐一访问，确认均为 200 且可正常加载；
3. 页面样式与脚本有无加载失败；
4. 不携带凭据直接访问管理接口，是否被正确拒绝；
5. 检查是否存在任意 404 资源；
6. 报告 HTTP 是否强制跳转到 HTTPS。

有任何一项不通过，请直接给出原因与修复方案，不要自行悄悄修改配置。
```

## 七、分层排障

```
域名 https://app.example.com 打不开，请在服务器上按以下顺序逐层排查，
每一步都给出实际命令与实际输出，最后给出根因与最小修复方案：
1. 应用进程/容器状态  2. 端口监听地址  3. 系统防火墙
4. 云侧安全组  5. 反向代理配置与错误日志  6. 证书有效期。
```

---

## 八、日常巡检（可设为定时任务）

```
请对我账号下的 Lighthouse 实例做一次巡检，用表格输出：
1. 实例状态、配置规格、公网 IP、到期时间与剩余天数；
2. 最近 24 小时 CPU / 内存 / 带宽峰值，标出异常时段；
3. 当前防火墙规则清单，标出建议收敛的项；
4. 磁盘使用率与是否需要清理；
5. 结论：需要我立即处理的前三项，并给出具体操作步骤。
```
